# AWS S3 & S3-Compatible Driver

The `provider/s3` package implements BlobKit's high-performance driver for Amazon S3 and all major S3-compatible object storage backends, including **Cloudflare R2**, **MinIO**, **Wasabi**, **Backblaze B2**, and **Google Cloud Storage (interoperability API)**.

Built on top of AWS SDK for Go v2 (`github.com/aws/aws-sdk-go-v2`), it delivers bounded streaming memory consumption, resilient connection pooling, rate-governed concurrent multipart uploads, and automated error sanitization.

---

## Key Capabilities & Highlights

| Capability | Supported | Description |
| :--- | :---: | :--- |
| **Direct Put Streaming** | Yes | Streams single-part uploads directly without buffering entire files in memory. |
| **Resumable Multipart** | Yes | Automatically fragments large streams into parallel parts with rate-limited memory buffers. |
| **Server-Side Copy** | Yes | Copies objects within the bucket or provider without downloading bytes to the application. |
| **Byte-Range Retrieval** | Yes | Supports standard HTTP range headers (`bytes=start-end`) for video streaming and resumes. |
| **Presigned URLs** | Yes | Generates secure, time-limited presigned URLs for both downloads (`GET`) and direct uploads (`PUT`). |
| **Batch Deletes** | Yes | Concurrently deletes up to 1,000 keys per S3 API call with automated error aggregation. |
| **Memory Limiter** | Yes | Global and per-upload concurrency and buffer throttling (`MemoryLimiter`). |
| **Error Scrubbing** | Yes | Redacts AWS secret keys, access tokens, and internal network IP addresses from error logs. |

## Configuration Reference

```go
type Config struct {
    // Name is the unique identifier for this driver instance (e.g. "s3-us-east-1", "r2-prod").
    Name string

    // Bucket is the target S3 bucket name.
    Bucket string

    // Region is the AWS region (e.g. "us-east-1", "auto" for Cloudflare R2).
    Region string

    // Endpoint is the custom endpoint URL for S3-compatible providers (R2, MinIO, Wasabi).
    // Leave blank for standard AWS S3.
    Endpoint string

    // AccessKey is the AWS Access Key ID.
    AccessKey string

    // SecretKey is the AWS Secret Access Key.
    SecretKey string

    // SessionToken is the optional temporary STS session token.
    SessionToken string

    // UsePathStyle forces path-style addressing (http://s3.local/bucket/key) instead of virtual-host.
    // Recommended for MinIO and local testing setups.
    UsePathStyle bool

    // PublicBaseURL specifies a custom CDN or public domain for URL resolution (e.g. "https://cdn.example.com").
    PublicBaseURL string

    // PartSize is the chunk size for multipart uploads in bytes (minimum 5 MiB, default 8 MiB).
    PartSize int64

    // MultipartThreshold is the payload size triggering multipart upload (default 16 MiB).
    MultipartThreshold int64

    // MaxConcurrentParts limits parallel goroutines uploading multipart parts (default 4).
    MaxConcurrentParts int

    // MemoryLimiter enforces a global RAM limit across all concurrent uploads.
    Limiter *MemoryLimiter
}
```

## Provider Configuration Recipes

### 1. Amazon Web Services (AWS S3)

```go
package main

import (
    "log"

    "github.com/suhwr/blobkit"
    "github.com/suhwr/blobkit/provider/s3"
)

func initAWSS3() (*blobkit.Client, error) {
    driver, err := s3.NewDriver(s3.Config{
        Name:               "aws-primary",
        Bucket:             "my-company-production-media",
        Region:             "us-east-1",
        AccessKey:          "AKIAIOSFODNN7EXAMPLE",
        SecretKey:          "wJalrXUtnFEMI/K7MDENG/bPxRfiCYEXAMPLEKEY",
        MultipartThreshold: 16 * 1024 * 1024, // 16 MiB
        PartSize:           8 * 1024 * 1024,  // 8 MiB
        MaxConcurrentParts: 4,
    })
    if err != nil {
        return nil, err
    }

    return blobkit.New(blobkit.WithDriver(driver))
}
```

## Memory Bounded Streaming & MemoryLimiter

Standard S3 multipart uploaders often allocate unbounded buffers into RAM when concurrent workers upload large files, risking out-of-memory crashes (`OOMKilled`) in containerized environments.

BlobKit provides the `s3.MemoryLimiter` primitive, implementing a thread-safe token bucket over RAM allocations:

```go
// Enforce a hard 64 MiB ceiling across the entire application process
limiter := s3.NewMemoryLimiter(64 * 1024 * 1024)

driver, err := s3.NewDriver(s3.Config{
    Name:    "s3-bounded",
    Bucket:  "large-payloads",
    Limiter: limiter,
})
```

### Concurrency & Context Safety
- If memory is exhausted, `Acquire(ctx, bytes)` blocks until another part completes and calls `Release(bytes)`.
- If the incoming request is cancelled (`<-ctx.Done()`), `Acquire` aborts immediately, waking up any sleeping goroutines without deadlocks or memory leaks.

## Presigned URLs for Secure Direct Client Access

Offload upload and download bandwidth from your Go application directly to S3 using presigned URLs:

```go
// Download URL valid for 15 minutes
presignedGet, err := client.PresignGet(ctx, obj.ID, blobkit.PresignOptions{
    Expiry: 15 * time.Minute,
})
if err != nil {
    return err
}
fmt.Println("Client Download Link:", presignedGet.URL)

// Upload URL valid for 10 minutes
presignedPut, err := client.PresignPut(ctx, "invoices/2026/INV-102.pdf", blobkit.PresignOptions{
    Expiry:      10 * time.Minute,
    ContentType: "application/pdf",
})
if err != nil {
    return err
}
fmt.Println("Client Direct Upload Link:", presignedPut.URL)
```

## Error Handling & Security

All underlying AWS SDK errors are parsed and normalized into standard BlobKit sentinels:
- `blobkit.ErrObjectNotFound`: S3 `NoSuchKey` / `NotFound` (404).
- `blobkit.ErrPreconditionFailed`: ETag mismatch or If-Match failure (412).
- `blobkit.ErrBucketNotFound`: `NoSuchBucket` (404).
- `blobkit.ErrInvalidKey`: Keys containing `..`, null bytes, or invalid path traversal segments.
- `context.Canceled` / `context.DeadlineExceeded`: Correctly unwrapped and preserved.

Sensitive credentials such as AWS access tokens, signature strings, and internal dial IP addresses are automatically scrubbed via regular expression filtering before returning error messages to loggers or clients.
